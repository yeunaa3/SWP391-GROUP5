# SRS UI reference

This folder contains the 53 screen-layout images embedded in the current SRS.
Each image is named with the official screen ID (`PUB-01` through `CFG-06`).

Implementation rule:

1. Treat the matching image as the visual source of truth for page structure.
2. Reuse the shared public header, authentication shell, or role workspace shell.
3. Keep the fields, actions, statuses, and permissions specified in SRS Section II.
4. Do not add a left sidebar to public or authentication screens.
5. Business, Ad Manager, and Administrator pages use the dark sidebar and white top bar shown in their reference images.
